What changed
  • Body text is now 16px; metadata and navigation are 14px.
  • Near-duplicate heading sizes now share five font roles.
  • Header, main content, and footer share gutters and a 1120px maximum.
  • Standalone controls have a 44px minimum height.
  • Team portraits use a shared 4:3 ratio.
  • Internal links use → and external links use ↗.
  • Dormant dark-mode colors were removed from the light stylesheet.

   
Responsive rules
At 960px navigation takes a separate row. At 720px, hero and detail pages stack, gutters reduce, and the team grid uses two columns. At 480px, team and lower homepage sections use one column. The header breakpoint accommodates the larger text.

   
Accessibility checks

These pairs meet the 4.5:1 normal-text threshold. The 44px control height is our usability target; WCAG 2.2 AA specifies 24px with exceptions. Native focus indicators are preserved. This is not a full accessibility audit.

   
Before production
Verify zoom and reflow, keyboard order, screen-reader semantics, real page URLs, back/forward behavior, and focus after navigation. The prototype still switches views locally.

   
Keep it small
Use an existing role before adding a value. Make a new token only when it expresses a reusable design decision. Update design.css, design.md, and this reference together.
